# 部署可用性与稳定性报告

- 日期：2026-11-14
- 结论：**当前为本地运行模式，没有稳定公网入口**；未创建任何付费资源。

## 1. 部署类型判定

| 类型 | 是否符合 | 证据 |
|---|---|---|
| 本地运行 | **是** | `run_system.bat` / `run_system.sh` 启动 Streamlit 8501 |
| Cloudflare 临时隧道 | 否 | `cloudflared.exe` 已移入 `.local_materials/`，未运行隧道 |
| 长期稳定云服务器 | 否 | 无云主机、无域名、无反代配置 |
| 其他部署 | 否 | 无 |

## 2. 实测项目

| 项目 | 结果 |
|---|---|
| 服务启动 | 干净环境首次 5.8 秒，HTTP 200 |
| 页面访问 | 概览/主题/排行/策划案四页无异常 |
| 服务重启 | 停止后重启 6.7 秒，HTTP 200 |
| 日志追踪 | Streamlit stdout 输出启动地址与端口 |
| 数据加载 | 1984 条记录、7 个来源、25 个批次 |
| 部署失败恢复 | 数据缺失降级正常；切换脚本失败自动回滚 |
| 关键接口安全 | 本地无鉴权；公网暴露前必须加认证和反代 |
| 大文件处理 | result1 约 1 MB；无超大文件进入提交包 |

## 3. 稳定性检查

- 启动脚本检测 `.venv`，缺失依赖时自动安装；
- 端口 8501 被占用时，Streamlit 会报错退出，需先释放端口；
- 页面数据加载有缓存（主数据 300 秒，结果 60 秒），刷新按钮可清缓存；
- 缺少 result3/result4 时页面降级为提示/Mock，不崩溃；
- 结果切换脚本在服务运行中拒绝发布，避免混合版本；
- 备份目录 `results/_switch_backups/` 保留最近切换前的文件，失败可回滚。

## 4. 公网部署评估

若需要公网演示，至少需要：

1. 负责人批准；
2. 反向代理 + 认证（Streamlit 本身无内置账号体系）；
3. 域名与 HTTPS；
4. 资源费用评估与批准；
5. 访问日志与数据脱敏。

在这些条件满足前，不宣称稳定公网部署，也不创建新的付费资源。

## 5. 已知限制

- 只能保证本机 Windows 环境实测；Mac/Linux 仅脚本静态检查；
- 无进程守护（systemd/Windows 服务），关机或终端关闭后服务停止；
- 无集中日志采集，日志输出到终端；
- 公网访问需要额外的安全加固。

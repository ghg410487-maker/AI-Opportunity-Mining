# v1/v2公平对照报告

## 当前可报告结果

两版均逐条运行同一份1984条冻结主表。v1分布为机会42、非机会1347、REVIEW 595；v2为机会16、非机会1367、REVIEW 601。v2相对v1发生：1→REVIEW 30、REVIEW→1 4、REVIEW→0 29、0→REVIEW 9。状态变化不是准确率变化。

无付费API的三次本地计时中，v1处理中位数0.028149秒（约70483条/秒），v2为0.133766秒（约14832条/秒）。两者均足以支撑1984条实时批处理；计时仅衡量规则判断，不含文件I/O，具体时延会随机器负载波动。

## 锁定评价设计

评价集`stage3e3_locked_126_v1`包含：42条v1机会全量审计、42条v1非机会分层概率样本、42条v1 REVIEW分层概率样本。分层变量为v1状态、来源和证据层级，每条保存N/n、入样概率及逆概率权重。

42条机会只能直接估计v1候选精确率，不能估计全量Recall、Accuracy或Macro-F1。只有126条全部完成独立人工审核后，才运行加权Precision、Recall和二分类Macro-F1；若类别支持不足，报告混淆矩阵和支持数，不突出Macro-F1。

当前已接入郭对42条v1机会候选的逐条审核：12条机会、29条非机会、1条INSUFFICIENT。该子集可报告v1候选确认率29.27%（12/41可判）和v2在同一子集的条件对照；另外84条仍未完成，因此全量Precision、Recall和Macro-F1继续为`PENDING_HUMAN_REVIEW`。详见`v1_v2_guo42_human_comparison.md`。

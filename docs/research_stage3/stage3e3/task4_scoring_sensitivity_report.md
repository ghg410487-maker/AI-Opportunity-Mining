# Task 4评分敏感性报告

## 实验范围

保留普通加权分和λ证据约束方案；新增五项权重分别±20%并重新归一化、按来源等权重算、缺失需求证据惩罚和Top-3一致性检查。

## 结果

- λ=0—1的证据约束未改变五簇排名，只改变数值。
- 十组单项权重±20%均保持原排序，Kendall τ=1，Top-3重合3/3。
- 缺失需求证据惩罚保持原排序，τ=1，Top-3重合3/3。
- 来源等权重算使C004与C005互换，τ=0.8，但Top-3集合仍为3/3。

这说明当前Top-3对一般权重扰动稳定，但第三、第二名内部次序对来源集中程度敏感。数值稳定和排序稳定不等于实际评价质量已被人工验证；在机会真实性核验和主题人工评价完成前，评分只作为可复算排序工具。

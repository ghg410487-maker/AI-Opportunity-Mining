# 面向郭的论文方法与实验摘要

本研究将教育相关性筛选与AI应用机会判别分离。T0只判断材料是否涉及教育活动；Task 2进一步从问题明确性、需求真实性、AI核心性、可行性和未满足程度进行判别，并保留1、0和REVIEW三种内部状态。REVIEW表示现有证据不足或规则边界未决，不自动等同于非机会。

规则基线v1在1984条冻结记录上产生42条机会、1347条非机会和595条REVIEW。改进候选v2强化直接需求、调研反馈、采购及实际使用证据，并区分产品宣传与用户需求，得到16条机会、1367条非机会和601条REVIEW。由于人工评价尚未完成，这一变化只说明决策边界更保守，不代表性能提高。

公平评价集锁定126条，包括全部42条v1机会及按来源、证据层级分层概率抽取的42条非机会和42条REVIEW。42条机会可用于候选精确率审计；全量Recall和Macro-F1必须等分层评价集完成后采用抽样权重计算。

Task 3比较字符TF-IDF与中文词/字混合特征、k=3—6和五个随机种子。混合特征改善词面轮廓代理，但存在小簇风险，正式基线暂不切换。Task 4对证据约束参数、权重扰动、来源等权和需求证据缺失进行了敏感性分析；Top-3整体稳定，但C004/C005次序对来源权重敏感。

论文必须明确：当前机器标签不是金标准，算法性能指标待独立人工核验；T0教育相关性也不等于需求真实、价值高或适合商业化。

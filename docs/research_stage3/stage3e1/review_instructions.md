# 郭的阶段3E-1独立审核说明

## 42条机会审核

逐行访问`source_url`，在批准的受控环境核对原文。公开表只提供记录ID、来源、机器结果、六维状态和风险提示，不能替代原文核验。

填写`human_opportunity_decision`、`human_review_reason`、`human_evidence_quality`和`review_status`。机器判断不得复制为人工最终意见；初始`review_status`统一为`PENDING`。

重点区分：产品/课程宣传是供给证据，不等于真实用户需求；T0教育相关不等于机会成立；原文不足时记录`INSUFFICIENT`或风险，不补写证据。

## 5个主题审核

检查簇内ID是否语义一致、主题名是否过宽或重复、独立来源数是否足以支持结论，以及程序评分是否被单一来源或宣传文本放大。填写主题命名意见和证据质量意见，不直接覆盖机器字段。

受限原文必须由负责人通过批准的受控方式提供。不得把公开索引当作已完成原文核验，也不得向公开仓库复制大段第三方内容。

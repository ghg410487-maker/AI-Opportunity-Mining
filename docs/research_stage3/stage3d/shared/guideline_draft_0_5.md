# T0教育相关性标注指南 draft-0.5

版本日期：2026-11-14  
状态：吸收R1—R9及26条负责人裁决的修订草案，**未冻结为T0 V1.0**。  
历史版本：draft-0.3、draft-0.4及其批准版全部保留。

## 1. 两个独立评价维度

### 1.1 T0教育相关性

T0回答：材料是否涉及真实、可识别的教学、学习、评价、实验实践、培训、教师发展或教育管理活动？标签为DIRECT、WEAK、NON、UNKNOWN。

### 1.2 真实痛点与需求强度评估

该维度独立回答：是否存在真实用户痛点、痛点强度、频率、未满足程度、付费意愿、产品效果和商业价值。教育AI产品、课程或工具在T0判DIRECT，不代表需求已验证；T0为NON也不能由模型自动推导商业结论。两套字段、证据和结论必须分开保存。

## 2. 证据层级

| 层级 | 可支持的结论 | 强制记录 |
|---|---|---|
| 完整正文/README/Issue | 主旨、功能与活动流程 | 原始URL、正文状态、SHA256 |
| 正式摘要或完整可用片段 | 摘要覆盖范围内的主旨与功能 | 标记ABSTRACT/FRAGMENT，不表述为全文结论 |
| 可信标题 | 可支持明确教育用途判断 | 标记TITLE_ONLY，不能冒充正文 |
| 辅助镜像、转载或同题新闻 | 补充上下文 | 实际URL、与原页关系；不得升级为原始全文 |

来源限制与标签是两个字段。标题或辅助来源可以被负责人用于裁决，但证据等级不得随标签升级。

## 3. 四分类

### EDUCATION_DIRECT

材料的主要对象、实际用途或可执行功能明确服务教育活动。核心判断是“是否存在实际教育任务”，不是教育关键词数量，也不要求额外证明真实需求。

- 正例：`B11-S00322`虽为通用电脑产品，但材料具体服务教师备课、多媒体教学等实际任务；负责人裁决DIRECT。
- 正例：`SUPER_part10-S00128`包含培训机构排课、课时及学员管理，构成实际教育管理功能；负责人裁决DIRECT。
- 正例：`SUPER_part2-S00206`直接作用于高校课程和教师评价表单，负责人裁决为教育管理DIRECT；工具价值或使用伦理另评。
- 反例：仅出现“适合学生、校园客户、教师购买”而没有实际教育任务，不能仅凭身份或关键词判DIRECT。

### EDUCATION_WEAK

教育用途是次要但可解释的场景，或证据能建立教育关联，却不足以确认实际教育任务为核心。WEAK不表示需求弱或产品差。

- 边界例：`B10-S00235`学术支持服务建立教育联系，但当前展示证据不足以确认完整核心任务；负责人裁决WEAK。
- 边界例：`B12-S00191`工业仿真出现规范化训练，但培养对象和教学关系不充分明确；负责人裁决WEAK。
- 边界例：`B12-S00299`实验设计标题及辅助转载建立教育关联，但原始正文未恢复；负责人裁决WEAK并保留来源限制。

### NON_EDUCATION

材料主旨明确属于非教育活动，教育词只是修辞、表达方式、人物身份、地点或偶然例示。

- 反例：`B14-S00132`完整Issue讨论菜谱步骤图片、视频和成品图，“视频教学”只是呈现方式；负责人裁决NON。

### UNKNOWN

仅用于材料不足、损坏或不可解释，导致无法可靠选择前三类。UNKNOWN不是低confidence、待裁决或边界困难的替代词。可在信息不足本身很明确时给高confidence UNKNOWN。

## 4. DIRECT与WEAK决策检查

1. 写一句不含标签的主旨摘要。
2. 找出主要对象：谁在使用、学习、教学或管理？
3. 找出实际用途：产品或材料具体执行什么任务？
4. 找出教育活动：授课、备课、学习、练习、批改、考试、实验、培训、课程或教务管理是否真实存在？
5. 若教育活动是核心工作流或明确主要用途，判DIRECT；若只是次要但持续、可解释的应用场景，判WEAK；若只是偶然提及，判NON。
6. 不按教育文字占全文比例机械判断，也不以是否为产品供给、是否证明痛点决定T0标签。

## 5. 标题、科研、竞赛、培训与教师身份

- 可信标题明确主体与教育任务时可支持DIRECT，但必须标记TITLE_ONLY。
- 学生参与科研不自动等于教育活动；须有课程、导师指导、研究训练或能力培养。
- 竞赛和培训须判断是否存在课程、训练、指导、练习或反馈，不能只凭获奖结果。
- 教师身份不等于教育用途；普通办公消费不因购买者是教师而升级。教师备课、授课、评价、教务或作为学习者参加研修时才进入教育判断。
- `SUPER_part17-S00025`由负责人依据标题及明确标识的辅助新闻裁决DIRECT，但原视频未恢复状态永久保留，不能把辅助新闻写成视频全文。

## 6. 填写要求

每条记录必须包含：原文证据摘录、证据层级、主旨摘要、标签理由、confidence、来源URL及来源恢复状态。理由必须说明实际教育任务及相邻标签为何不适用。confidence衡量判断稳定性，不是模型概率、需求强度或产品价值。

# Task 4证据质量约束评分

## 方法

普通加权分保留阶段3E-1公式。新增证据质量Q（0—100），由文本层级25分、原文可定位摘录20分、需求真实性25分、直接需求证据15分、实际使用/采购/部署证据15分构成。它衡量证据支撑，不等同于机会价值。

约束公式为 `S_constrained = S_ordinary × [1 - λ × (1 - Q/100)]`。默认λ=0.5；λ=0保持普通分，λ=1完全按证据质量折减。

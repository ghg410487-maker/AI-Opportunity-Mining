# AI 工具使用记录

## 1. 使用说明

本文件用于持续记录项目中实际发生的 AI 工具使用，支持最终编制比赛要求的 AI 使用报告。只记录真实调用，不预填、不补写不存在的使用记录，不把模板字段当成已完成事实。

每次产生会影响代码、数据、算法、实验、图表、论文或决策的 AI 使用后，由实际操作者补充一行。相同工具在不同版本、不同环节或不同关键提示下分别记录。涉及敏感信息、API Key、个人信息或未公开数据时，只记录必要摘要，不粘贴秘密或个人数据。

## 2. 记录字段定义

| 字段 | 填写要求 |
| --- | --- |
| 记录编号 | 建议格式 `AI-YYYYMMDD-序号`，同日递增 |
| 日期时间 | 实际使用时间，注明时区或统一使用北京时间 |
| 操作者 | 实际使用该工具的团队成员 |
| 工具/服务 | 例如 Codex、ChatGPT、DeepSeek API、本地模型 |
| 模型及版本 | 填写界面/API 显示的准确模型和版本；未知则写“未显示”，不得猜测 |
| 使用环节 | 需求分析、代码、数据处理、标注、建模、实验、图表、论文等 |
| 使用目的 | 说明为什么使用以及预期产物 |
| 输入材料 | 概述提供给工具的文件、数据范围或上下文，不记录密钥和敏感信息 |
| 关键提示词 | 保存能够影响结果的核心提示；过长时记录日志文件路径或摘要 |
| 回复摘要 | 客观概述 AI 返回内容，不把建议写成团队结论 |
| 团队采纳 | 全部采纳、部分采纳、未采纳，并说明采纳部分 |
| 人工核验与修改 | 记录事实核验、代码审查、重算、改写和最终责任人 |
| 产物/证据位置 | 对应 commit、文件、实验编号或报告章节 |
| 风险与备注 | 幻觉、版权、偏差、不可复现、版本不明等问题 |
